# Corpus

Coding conversations for the compactor experiments.

* [tasks.py](tasks.py) - v1 tasks: reference solutions, behavior tests, one planted file constraint
* [build.py](build.py) - builds v1 conversations and validates each reference against its tests
* [tasks_v2.py](tasks_v2.py) - v2 tasks: a planted decision stated only in an early history turn
* [build_v2.py](build_v2.py) - builds v2 conversations (about 3,250-token histories) and validates references
* [conversations/](conversations/) - v1 conversation JSON files (12)
* [conversations_v2/](conversations_v2/) - v2 conversation JSON files (12)
